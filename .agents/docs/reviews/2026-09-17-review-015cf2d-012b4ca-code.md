## Findings

- **[medium / confidence: high]** `README.md:46` — stale restatement of the disproved dry-run
  claim. It reads: "`sh-agent report --dry-run`, read what it would send, then `sh-agent report`".
  The security review (finding 1, `2026-09-17-security-6af54f7-015cf2d.md`) established that
  `--dry-run` prints only the redactions that *fired*, never the file contents, so it "cannot show a
  secret it missed." This same commit rewrote the identical claim in `local.md` ("Anything that
  matches no shape IS sent, and `--dry-run` cannot show it… read the originals under
  `~/.config/sh-agent/`") and in `remote.md` ("read the originals under `~/.config/sh-agent/` (the
  dry run shows what is caught, never what is missed)"), but `README.md` — not in this diff's file
  list — was never touched, even though it names the same subject (`report --dry-run`, "read"). This
  is the describing-text rule this project's own `AGENTS.md` states ("every other restatement of a
  changed rule is changed with it") and the exact failure mode BUG-003/007/027 exist to catch.
  Fix: reword `README.md:46` to match `local.md`/`remote.md` — read the originals first, dry-run
  shows only what was caught.
