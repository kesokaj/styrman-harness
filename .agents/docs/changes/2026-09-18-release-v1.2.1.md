# Release v1.2.1 — a release binary installs only what it carries     (2026-09-18)

## Summary

v1.2.1 is the fix for a silent failure the operator found by installing v1.2.0 on a second machine: `argolis-devbox` still carried an old unpacked bundle recorded in its manifest, so the release binary installed that tree's months-old content and reported `drift none` against it. A release binary now installs the harness built into it and never a tree on the machine, and refuses `--repo`/`$SH_AGENT_REPO` rather than appearing to accept one (ADR-034, BUG-077). A binary-only place also sheds the feedback clone earlier versions kept — only the checkout path did that before, so the machine that prompted this whole feature would have gone on holding every other place's reports. Two message fixes ride along: the not-found error says a build has no harness built in (BUG-076), and the kept-clone message says what its count measured (BUG-074).

## Verification

`VERDICT: SHIP`, range v1.2.0..86d57d8. Six findings, all fixed before the tag: a README paragraph that still stated the old source order; a regression where an exported `$SH_AGENT_REPO` made `report` send a null record on a release binary; `RemoveKeptClone` not refusing git's redirect variables on a path that deletes; a refusal that named a path but not which flag carried it; the working-directory walk pinned by no test; and the trail's internal identifiers needing a publication check. At the tag: 104 top-level tests and 87 subtests, none failing or skipped; `gofmt`, `go vet`, `go test -race`, `govulncheck` clean; install into a scratch home with drift none; and the release-binary rule confirmed in four scenarios with a real `-ldflags` binary — plain install, `--repo` refused naming the flag, an exported `$SH_AGENT_REPO` refused naming the variable, and `report` unaffected by that variable. Five mutations each fail the test that covers them. Not exercised: anything on darwin, and `update` from v1.2.0 to v1.2.1 against the real release, which cannot exist before the tag.
