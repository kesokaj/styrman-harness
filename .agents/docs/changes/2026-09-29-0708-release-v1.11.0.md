## Improvements and optimisation
- **The verifier finishes its gate:** its turn budget rises from 30 to 45, the direct answer to gate runs cut off at 30.
- **The feature skill:** inputs that always travel together (a set of secret files, a host's connection values) are one input, not one flag each.
## Other updates
- **Global context rules:**
  - a low finding whose fix would add a flag, a refusal or a step for the operator is offered as a one-line choice and recorded `left: operator`, not built; during a release it is accepted into the release entry and the choice goes to the handoff;
  - "Is it live?" is answered with the fact and an offer to run `/preflight`;
  - a finished agent that still has background work running is stopped.
- **The research skill:** a finding about another project stays out of this project's plans, handoff and issue lists.
- **Withdrawn before release:** three retro rules (a verifier shared-call rule, a verifier long-suite rewording, and a feature-skill early exit at the cold-read cap). Each failed review rounds and was struck; the long-suite rule is re-queued for a later release with a behavioural run of its own.
