## Excluded

Upstream entries that are not vendored, with the reason. The refresh script excludes every name listed here; `TestCatalogExcludedEntriesAreAbsent` fails if one is in the catalog.

- `agent-platform-migrate-from-ai-studio` — its OpenClaw steps create a key for the default Compute Engine service account, write it over the user's gcloud application-default credentials, copy it to a VM and ask the user to disable the org policy that blocks key creation (security review 2026-10-01)
- `finding-google-skills` — it fetches Google's skill index from google/skills `main` and follows the skills it names at run time, bypassing the pin, the checksums and the review; the router greps this catalog's own index instead (security review 2026-10-01)
- `firebase-basics` — its mandatory setup installs the Firebase plugin, every `firebase/agent-skills` skill and an `npx -y firebase-tools@latest` MCP server into Claude Code and Antigravity, unpinned, unasked and self-updating (security review 2026-10-01)
- `google-agents-cli-onboarding` — its setup (`uvx google-agents-cli setup`, `agents-cli setup`, `npx skills add google/agents-cli`) installs unpinned skills into the CLIs' own skill directories, which the catalog exists to avoid; the agents-cli skills themselves are entries here (security review 2026-10-01)
- `google-cloud-recipe-foundation-builder` — on a Permission Denied it grants the active identity organisation- and billing-level admin roles and retries, outside the one approval it asks for (security review 2026-10-01)
