# v2.7.0 gate fixes: BUG-171, the dream signal relay, the timer's home, redaction kinds, disallowedTools off the allow-list     (2026-10-12)

## Summary
The release gate's reviewer and security agents reviewed v2.6.2..13c5bde. Nothing blocked; every finding was low. The operator chose what went in. Round 1 fixes:
- **BUG-171:** a bad `--vendor` is a usage error, exit 2, for every verb before the verb does anything. Before, `update` fetched and pulled the checkout first and exited 1, `--dry-run` never checked the value, `status` exited 1, and `uninstall` and `report` took any word.
- **The dream signal relay:** `relay()` still takes a signal already queued when the CLI ends, and `callWithin` waits for it before the next project.
- **The timer:** it checks the home as given, not only through the cleaned binary path.
- **The command-line credential rule, three more shapes (operator's choice):**
  - an escaped `\n`, `\r` or `\t` written out before the flag;
  - a quote around the user and the password;
  - six clients' password flags: mongosh/mongo and sqlcmd `-p`/`-P`, an LDAP tool's `-w`, OpenSSL's `pass:`, keytool's `-storepass`/`-keypass` and lftp's `-u user,password`.

Round 2 verified all six fixes and reached the review cap. The operator chose "Fix small ones, no round 3":
- OpenSSL's `pass:` is caught inside quotes too.
- Five harmless over-redactions are pinned.
- README and the local deploy guide now say `update --vendor all` widens a single-vendor install.
- `disallowedTools` leaves the agent allow-list (ADR-056a), because Antigravity's derived agent drops it.
