# Release v2.6.2

## Type

release

## Summary

A PATCH release. `sh-agent dream` now logs in to Antigravity on macOS (BUG-166). Gate: `reviews/2026-10-09-preflight-v2.6.2.md`, VERDICT SHIP.

## Release notes

## Fixes
- **`sh-agent dream` works on macOS with Antigravity** (BUG-166). It used to refuse every run with "no Antigravity login at …/antigravity-oauth-token". agy keeps its login in the Keychain there.
  - **The login:** the dream job's private agy home now links `~/Library/Keychains`; it is never copied. The dream job's agy shares your normal agy login, and tool calls are still refused.
  - **A clearer failure:** when agy asks for a browser login (for example, a locked Keychain), the failure line says `agy is not logged in inside the dream job's private HOME` instead of `invalid output`.

## Install or update
- **A checkout place:** `sh-agent update`.
- **A binary-only place on v2.4.0 or later:** `sh-agent update` downloads v2.6.2 and checks it against `SHA256SUMS`.
- **A place still on v2.3.2 or older** cannot update past the v2.4.0 bridge by itself. Replace `~/.local/bin/sh-agent` with this release's binary for your platform by hand, then run `sh-agent install`.
- **A zip place:** download `styrman-harness-v2.6.2.zip`, then run `sh-agent update --from-zip styrman-harness-v2.6.2.zip`.
