# v1.13.0 gate fixes   (2026-09-30-0505)

The release gate for v1.13.0 (its report, `reviews/2026-09-30-preflight-v1.13.0.md`, is written in the release commit) ran over v1.12.1..c872598. Its reviews found four low findings; three are fixed here before the tag, one is a documented limit by the operator's choice. The security check of these fixes then found one more pre-existing low, fixed in the second gate-fix commit: every file read goes through an `os.Root`, so a skip-worktree file under a directory turned into a symlink can no longer be read from outside the checkout (`TestReadsNeverLeaveCheckout`).

- **Copied index, documented** (security finding 2): the spec's failure modes say an index is only as trusted as the folder it sits in and name `sh-agent index --rebuild` after copying a project in.
- **Docs lens** findings on the two closed bug records: rebutted in the report's Outcome (a record's body is history; its status is the living value).
