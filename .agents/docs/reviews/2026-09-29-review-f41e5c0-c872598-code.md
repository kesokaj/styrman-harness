## Findings

- **[low / confidence: high]** `internal/search/security_test.go:230-249` (`TestRefuseSymlinkedDatabase`, the `search.db` case)
  - **What is wrong:** the victim file holds `"keep me"`, which is not a SQLite database. In the mutation run described below, SQLite hit NOTADB. `openStore` printed "unreadable … rebuilt", and `removeDB` unlinked the link and left the victim alone.
  - **Why it matters:** the only assertion that failed there was the refusal-string check (`security_test.go:245`). The `data != "keep me"` assertion stayed silent. It cannot fail in this arrangement, so it does not prove that nothing was written through the link.
  - **The measured arrangement:** the security finding this test answers (`2026-09-29-security-aae16af-f41e5c0.md`, finding 1) used an EMPTY target, which grew from 0 to 86,016 bytes. The global rule wants the test built on the arrangement the finding measured.
  - **Impact:** the trigger itself is still covered, because the refusal assertion fails without the fix.
  - **Fix:** give the `search.db` case (and the global case) an empty victim file, and assert that it is still 0 bytes. The write-through assertion then fails without the fix.
- **[low / confidence: medium]** `internal/search/store.go:160-168` (`prepareFiles`)
  - **What is wrong:** the comment "O_EXCL never follows a link put there since the check above" is true of `OpenFile` itself. But on `ErrExist` the function returns nil without looking again. A link planted between the `Lstat` loop and the `OpenFile` makes `OpenFile` return `ErrExist`, the link is accepted, and `sql.Open` then follows it.
  - **Why it matters:** the comment implies that window is closed, and it is not.
  - **Practical impact: negligible.** The attacker needs concurrent write access to the user's own `.agents/scratch` or `~/.config/sh-agent`. A swap of an existing regular file between check and open is inherent to opening by path.
  - **Fix:** on `ErrExist`, `Lstat` the path again and refuse a non-regular file. Otherwise reword the comment so that it claims only what the code does.
