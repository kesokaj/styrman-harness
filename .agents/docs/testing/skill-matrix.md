## Procedure

1. Sandbox home `<home>` logged in to both CLIs; `sh-agent install --home <home>`; demo service checkouts for each CLI (a three-file Go HTTP service with `/healthz` and `/hello`, scaffolded by `/init-project`, plus the `/version` task). Seeds: three identical tooling corrections appended to `<home>/.config/sh-agent/feedback.jsonl`; for the `bug` row, commit `sed -i 's/name = strings.TrimSpace(name)/name = strings.TrimLeft(name, " ")/' internal/greet/greet.go`.
2. Per row: fresh `git clone` of the demo into `/home/<user>/sandbox/runs/<cli>-<id>`, base as in the table, then
   - Claude Code: `HOME=<home> claude -p "<prompt>" --permission-mode acceptEdits <extra> --allowedTools "Bash(git:*)" "Bash(go:*)" "Bash(gofmt:*)" "Bash(cat:*)" "Bash(ls:*)" "Bash(date:*)" "Bash(mkdir:*)" "Bash(pwd:*)" "Bash(grep:*)" "Bash(find:*)" "Bash(wc:*)" "Bash(head:*)" "Bash(tail:*)" "Bash(printf:*)" "Bash(echo:*)" "Bash(cp:*)" "Bash(ln:*)" "Bash(test:*)" "Bash(diff:*)" "Bash(curl:*)" "Bash(sh-agent:*)" "Bash(chmod:*)" "Bash(bash:*)" "Bash(python3:*)" "Bash(for:*)" "Bash(readlink:*)" "Agent" --output-format text` with `PATH=<home>/.local/bin:$PATH`. No `gcloud`, `docker`, `terraform`, or `npx` in the allowlist: a cloud command is denied, which is the mock.
   - Antigravity: `HOME=<home> agy -p "The project root is the current directory, <dir>; ignore any other checkout. <prompt>" --mode accept-edits --print-timeout 20m`, with `<home>/.gemini/antigravity-cli/settings.json` holding `"permissions": {"allow": ["command(*)", "read_file(*)", "write_file(*)", "edit_file(*)", "list_dir(*)"]}`. No `--add-dir`.
3. Run the check in the clone with `OUT=<stdout file>` and `SB=<home>`; exit 0 is PASS. A check cell writes each `|` as `\|`, the table's escape, so a kit built from this file unescapes it before running the check. Then read the CLI's transcript (Claude: `<home>/.claude/projects/<encoded dir>/*.jsonl`, `Skill` and `Agent` tool uses; Antigravity: `<home>/.gemini/antigravity-cli/conversations/*.db`, `steps.step_payload`) for skills loaded and agents dispatched, and audit every executed command for `gcloud|terraform|docker (build|run|push)|kubectl|git push|npx skills add`.
4. Drive with `xargs -P 4` (Claude) and `-P 3` (Antigravity) under a monitor that outlives a ten-minute tool timeout. Never edit the driver while runs are in flight.
