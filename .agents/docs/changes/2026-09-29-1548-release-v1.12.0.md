## Release notes
## New features
- **`/review --prompts`**: a prompt-audit lens over instruction files on both CLIs, through the reviewer with Anthropic's prompt-audit reference vendored verbatim (Apache-2.0); a Claude-only rationale is a flag, a prohibition backed by a bug row or an ADR is a keep; report and proposed diff, never applied.
- **`/dream`**: consolidates the project's auto memory — one verdict per memory (keep, graduated, stale, broken, merge; `promote` as a flag), the index rewritten, a dry-run gate, a record in `retros/`, promotions handed to `/retro`.
- **One memory store for both CLIs**: `.agents/memory/` in the project, gitignored, one per checkout; `/init-project` Step 5b writes `autoMemoryDirectory` into the per-machine `.claude/settings.local.json`, creates the store and moves an existing default store in, after a trust check; Antigravity sessions read the store's index at resume and `feedback-log` writes memory files there.
- **The `dreamer` agent**: the learning loop's consolidation judgement by a reader who did not write the memories — rule, skill and procedure candidates with evidence from the store and the trail, dispatched by `/retro` after `/dream` and by `/distill`; proposes only.
## Improvements and optimisation
- `/retro` reads the memory verdicts and the dreamer's candidates first and applies approved verdict edits with the proposals; `/distill` takes the dreamer's skill candidates first.
- The global context names `/dream` and the `dreamer` in the learning loop and reads `.agents/memory/MEMORY.md` at resume on Antigravity.
- The docker skill's `.dockerignore` minimum gains `.agents/memory`.
## Fixes
