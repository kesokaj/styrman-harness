# Release v1.10.0     (date: 2026-09-28)

## Summary
v1.10.0 is gated SHIP over `v1.9.0..e33a4e1` (`reviews/2026-09-28-preflight-v1.10.0.md`).

## Type
release

## Release notes
## Improvements and optimisation
- **The zip place accepts the zip it is given** (ADR-041). `sh-agent update --from-zip <file>` now installs any zip that does not have both `SHA256SUMS` and `SHA256SUMS.sig` beside it, marked `UNVERIFIED`. That covers a zip with neither file, or with only one of them, which v1.9.0 refused.
  - A release zip with both files beside it is still verified automatically, and refused if the check fails.
  - The zip place is the fallback for machines that cannot take the normal way in, so it asks for nothing extra.
## Other updates
- **Tighter tests:** the zip refusal tests now assert which refusal fired, and new tests cover a half pair end to end.
- **Decision records:** ADR-040 (an `--unverified` flag) was added and superseded by ADR-041 within this release, and was never shipped.
## Install
- **Download:** see README § Install without cloning. Existing binary-only places: `sh-agent update`.
- **Zip place:** run `sh-agent update --from-zip styrman-harness-v1.10.0.zip`. With `SHA256SUMS` and `SHA256SUMS.sig` from this release in the same folder, it says `VERIFIED`; without them, `UNVERIFIED`.
