## Question
Where do a new `sh-agent memory` verb and a `sh-agent dream [--all|--install-timer|--remove-timer]` verb plug into the code, and which text changes with them.

## Summary
Verbs are a flat switch in `run()` (cmd/sh-agent/main.go:85-349) over ONE shared FlagSet; search/index/report are dispatched before `ResolveSource` (main.go:152-183) because they need no harness tree, and delegate to `internal/search` / `internal/harness`. Redaction is unexported (`redactLines`, `redactDocument`, `needleIn`; report.go:128,199,257), needs an exported wrapper. The manifest holds paths relative to $HOME with no vendor-root restriction except `pruneEmptyDirs`' stop list, so a systemd/launchd file can be a `File` in `Plan` (no OS-specific precedent exists). No code runs `claude`/`agy` today. Six text places describe the memory store and all change together.

## Risks
- Redaction is credential needles only (whole-line). Transcripts contain full tool output, file contents and personal text; sending that to a model via headless CLI is a new disclosure path (the CLI is the same vendor the session already used, but agy transcripts sent to claude, or vice versa, cross vendors). Decide vendor policy and keep-local option. Proposals written from redacted text can still quote leaked content.
- Self-feed: dream's own headless call writes transcripts (claude) / conversations (agy) into the same stores it reads; filter by `entrypoint`/`--no-session-persistence`/timestamp.
- "No tools" is enforceable on claude (`--tools ""`) but not evidently on agy. Also prompt injection: transcripts and memory are data in the prompt; the model must only return text, and the Go side writes files (good: dreamer currently has Write).
- agy protobuf blobs are undocumented; a format change breaks silently. Plan for "transcripts unreadable -> name under not examined".
- Timer: install writes unit files but does not enable them; uninstall's file-only removal would leave an enabled unit pointing nowhere (systemd) or a loaded launchd job. pruneEmptyDirs stop list lacks the new dirs. A timer running `sh-agent dream --all` spends model quota unattended; needs a clear opt-in and a cap.
- LastRetro conflation (above); status exit code: drift rows for timer files on machines that did not opt in.
- Project list is only as complete as `register` calls; deleted checkouts (dropReason) and worktrees/duplicate roots.
- context/AGENTS.md budget 22000 bytes: rewriting the memory lines must not grow it.
- Replacing Claude native memory: concurrent writers (two sessions calling `sh-agent memory`) need atomic write + MEMORY.md index rebuild under a lock; index limits 200 lines/25KB.
- `sh-agent memory` must find the repo root from cwd (`git rev-parse --show-toplevel`) — worktrees, submodules, no-git dirs.
