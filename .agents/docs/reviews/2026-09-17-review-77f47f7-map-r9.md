Since ADR-031 is append-only and is the record future sessions will trust for where these rules live, this mismatch should be fixed in this same commit before it lands — cite `§ How the harness works` and either say "five" or drop the count.
- **[low / confidence: medium]** `AGENTS.md:17` — "The interactive page of the map is a view of this diagram: when the map changes, the page is regenerated from it, never edited on its own." No interactive page exists anywhere in the tree (checked for `*.html`/"interactive" artifacts) and this diff does not add one; ADR-031's own Context paragraph says the operator merely "approved an interactive page" as a future idea. The rule is written in the present tense as if the artifact already exists, with no dashed-line-style gap marker the way the README's Mermaid legend honestly flags the other two gaps. Low severity since it names no wrong behaviour today, but it will read as a false guarantee to the next session that goes looking for the page.
