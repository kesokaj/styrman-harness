# BUG-063 fixed; one testing guide per project (ADR-032)     (2026-09-17)

## Summary
The verifier could finish without writing the testing guide it owes and still log `Scope: complete`. Root cause: the guide duty was a paragraph beside the verifier's numbered steps, so a run skipped it outright (repro-5 never tried) or dropped it after one denied command (repro-6), and "complete" was defined by the commands run, not by the guide existing. Fix: `agents/verifier.md` step 4 checks for the guide and writes it before running anything; a guide not written is named on the Scope line as `guide not written: <why>`, and that Scope is never complete. Testing the fix also showed BUG-062's b093fd6 fix skipped in 1 of 5 runs, so the operator chose to delete the `<app>` level: ADR-032, one guide per project at `testing/guide.md`, with older `testing/<name>/guide.md` files moved (one) or merged (several). The `App:` log line from b093fd6 is removed.
