# v2.6.0 gate: a session belongs to the window it starts in

From the reviewer's round 7. `show` picked sessions that merely overlapped the window, with an inclusive end, so retro's two adjacent windows could both count a session running across, or starting at, the boundary. `Show` now selects sessions whose start lies in `[since, until)`. The "never overlap" wording in `metricsShowOptions` and retro source 11 is now true. Pinned by `TestShowAdjacentWindowsShareNoSession` (red before). The spec's `--until` row is updated. The dream, metrics and cmd tests pass.
