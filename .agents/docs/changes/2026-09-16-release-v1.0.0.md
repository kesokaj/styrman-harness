# v1.0.0: SSH-signed release for downstream consumption (2026-09-16)

## Summary
First annotated SSH-signed tag on `main` (range 4aa19be..0a67f3f, 17 commits). Styrman-crew is building a host-side channel that fetches this repository's newest signed tag, verifies it against a root-only allowed-signers file, and runs it as the agent harness. Until today there was no tag for it to consume. v1.0.0 encompasses: the release mechanism itself with SSH signing and verification binding to the gated commit (ADR-026); `sh-agent update` refusing a dirty checkout on every path (ADR-027, BUG-046, REQUIREMENTS.md R4 amended); installer hardening from the release gate — `Plan` and `copyTree` refusing secret-shaped filenames, `LoadSkills` refusing duplicate names, `Adopt` staging outside `skills/` with a restorable backup, `writeAtomic` syncing before rename, deployed files dropping group/other write; the toolchain pin episode (ADR-028 then ADR-029) whereby a `go1.25.8` pin that cleared two standard-library advisories was withdrawn after the gate measured it rendered the module unbuildable offline; six bug records closed in instruction text and five simulation follow-ups; the retro's six proposals. v1.0.0 ships with two established-unreachable `govulncheck` advisories: GO-2026-4602 (requires `os.Root` construction, not done here) and GO-2025-3956 (requires empty or dotted path to `LookPath`, literal "go" is passed).
