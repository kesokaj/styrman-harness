## Verdict: FINDINGS — all low, nothing that reopens the work

**All three round-3 fixes are correct and complete, and none introduced a defect in the Go code.** The
dry-run fix is the right shape and I validated its test in both states: unmutated, the test runs and passes
(`--- PASS`, verbose, so it is not a `-run` filter matching nothing); with the gate mutated back to
`if true`, it fails on the exact needle — `main_test.go:1485: install --dry-run made a PATH claim about a
binary it did not write ("so \`sh-agent\` runs")`. Completeness is by enumeration: `pathHint` has exactly one
call site (`main.go:277`), and on every non-dry-run path the installed binary really is written, because
`installFiles` errors out unless `selfExecutable()` returns bytes (`main.go:262-265`, `:632-640`, which has
no `return nil, nil`), so `Plan`'s `if selfExe != nil` guard (`plan.go:188`) cannot be skipped there. The
`allowed_signers` rename is one spelling in both documents, matches `internal/harness/release.go:234`, and
repairs the broken pointer round 3 named. The three fences are well formed and a whole-fence paste now runs
exactly one route.

The worst remaining item is a **residual sharpened by the fence split, not introduced by it**: the browser
route is now an independently copy-pasteable fence whose only executable content is `chmod +x` + `mv` of an
unverified download into `~/.local/bin/sh-agent`, with its three checks stated as prose above them
(`README.md:116-119`). The property the round-2 fix established for the `gh` route — unverified bytes cannot
become `~/.local/bin/sh-agent` — is the one property that fence lacks, and it is now the easiest fence to
paste alone. Everything else is bookkeeping about the record: the rewritten hung-mount reason **now holds**
with one refinement, `left` reason 1 holds on its first clauses and **fails on its fourth**, and `left`
reason 2 holds for the case it names but leaves two other cases in the same silent branch.

- **[low / confidence: high]** `internal/harness/pathguard.go:28-54` — the rewritten hung-mount reason
  **holds**, with one refinement worth having on the record. The rewrite ("the walk `stat`s every PATH entry
  ahead of the installed file, which is MORE than the shell does — the shell stops at its first match, so a
  shadow short-circuits it; the exposure is bounded by those entries and is the cost of naming every shadow
