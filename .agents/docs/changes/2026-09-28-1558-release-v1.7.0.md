## Release notes

## New features
- Time-sortable trail names: handoffs and change entries are now named `YYYY-MM-DD-HHMM-<slug>.md` (`date +%F-%H%M`), so name order is time order in any clone. The global context carries the rule, including that a date-only name is older than every timed name of its day. The handoff skill saves timed names; the changelog agent names its entry from the stamp its dispatcher passes (it has no Bash); `/preflight` passes that stamp. Proven behaviourally: 3 of 3 timed with the new text, 0 of 3 with the old, on Claude Code; both CLIs in a sandbox; an agy cold resume picked the true newest handoff 2 of 2 (BUG-089, BUG-090, BUG-091).
- `/init-project` on an active project warns when `handoffs/` or `changes/` hold date-only names, with a count, and never renames them.
## Fixes
