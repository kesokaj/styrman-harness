# Release v1.9.0     (date: 2026-09-28)

## Summary
v1.9.0 is gated SHIP over `v1.8.0..b5d4cb3` (`reviews/2026-09-28-preflight-v1.9.0.md`).

## Type
release

## Release notes
## New features
- **Signed release zip.** Each release now publishes `styrman-harness-vX.Y.Z.zip`, a `git archive` of the tag, under the signed `SHA256SUMS`.
  - `sh-agent update --from-zip <file>` verifies the zip when `SHA256SUMS` and `SHA256SUMS.sig` sit beside it, and prints `VERIFIED against the signed SHA256SUMS of release vX.Y.Z`.
  - It refuses the zip on any failed check, and nothing is written.
  - A zip with neither file beside it (a `main` zip) still installs, marked `UNVERIFIED` (ADR-039).
## Improvements and optimisation
- **The zip verdict is kept.** An install from a zip records in its manifest whether the zip was verified, and `sh-agent status` shows `(verified vX.Y.Z)` or `(unverified)`.
- **Refusals name the right file.** When the zip is not the one the release published, for example GitHub's automatic "Source code" archive, the refusal names the zip that release does publish.
## Fixes
- **The report sweep no longer builds a glob from the home path**, so a home containing glob characters cannot reach another home's clones.
- **Tests can no longer run the real `sh-agent report`:** they cut `PATH` first, so none can push to the feedback repository (BUG-094). The report a test pushed during v1.8.0 has been removed.
- **The pid in the sweep test is now deterministic**, so the test can no longer fail by chance.
## Other updates
- **`find-skills` is vendored verbatim again.** Its routing (a found skill goes into the harness checkout's `skills/`, then `sh-agent install`) now lives in the global context, including `npx skills add … -y`.
- **R9 wording:** "nothing in the zip replaces the binary".
- **The skill matrix drops `curl`.**
- **The README map** draws the release zip and the Releases → zip place path (by hand, verified).
## Install
- **Download:** see README § Install without cloning. Existing binary-only places: `sh-agent update`.
- **Zip place:** download `styrman-harness-v1.9.0.zip`, `SHA256SUMS` and `SHA256SUMS.sig` from this release into one folder, then run `sh-agent update --from-zip styrman-harness-v1.9.0.zip`. The output must say `VERIFIED`.
