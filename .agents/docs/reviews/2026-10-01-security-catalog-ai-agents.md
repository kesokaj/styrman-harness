# Security review — catalog-ai-agents   (2026-10-01)

Range reviewed: cf9c5e2, skills/google-catalog/catalog (slice: agent-platform, gemini, agents-cli, genkit; 30 entries)

Blast radius also read: the router `skills/google-catalog/SKILL.md` (it is what makes an agent follow these entries) and `catalog/MANIFEST.md` § Notes (where the notes land). `sh-agent search --refs skills/google-catalog --kind bug`: no past bug records.

## Status: COMPLETE

## Verdict: FINDINGS

The worst problem: `agent-platform-migrate-from-ai-studio` (OpenClaw section, `SKILL.md:272-286`) has the agent create a long-lived service-account key for the Compute Engine default service account. That account often holds `roles/editor`. The key is written over the user's own ADC file, `~/.config/gcloud/application_default_credentials.json`, and then copied to a VM with `scp`. Where the org policy blocks key creation, the entry tells the agent to "pause, and prompt the user to disable it". This is unnecessary: on GCE the attached service account is already available through the metadata server, as the same entry says at L114-117. Router step 4 does not cover service-account keys or org policies, so following this entry under the router's rules is still unsafe. Recommendation: exclude.

The next problem is in the delivery mechanism, not in an entry. The router never sends the agent to `MANIFEST.md` § Notes, so every per-entry note recommended below is inert until the router says to read the notes. Medium-severity findings: the agents-cli `setup` path installs unpinned code and writes skills into the CLIs' own skill directories, and the workflow entry's trigger for it always fires inside the catalog. `gcloud config set core/disable_prompts True` is a machine-wide, persistent change. agents-cli extensions turn a repo's YAML into arbitrary commands. `--no-confirm-project` is stated as a MUST. A push to `main` becomes a deploy. A managed-agent sample allows egress to `*`. `curl | bash` installers. Least-privilege gaps. No credentials or real keys were found anywhere in the slice.

Counts: 2 exclude, 26 note, 2 clean (gemini-api, gemini-interactions-api).
