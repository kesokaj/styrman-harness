## Findings

- **[low / confidence: high]** `internal/search/reconcile.go:352`.
  - **Where:** `readIndexable(filepath.Join(src.dir, filepath.FromSlash(e.path)))`, with `:200-205`. `os.Lstat` refuses only a symlink in the LAST component, and `os.ReadFile` follows a symlink in any parent. The entries come from the `git ls-files -s` view at `:86-106`.
  - **Pre-existing:** unchanged by 505732d, and present since the search index landed.
  - **Weakness:** `git ls-files -s` lists every index entry, including assume-unchanged (`h`) and skip-worktree (`S`) entries. `git status` never checks those in the work tree, so no ` D` record removes them from the view. When the entry's blob is new to the index, `applyLocked` reads it by joining the path to the checkout, and a symlinked parent directory redirects that read anywhere.
  - **Probe p2** (`.agents/scratch/secrev-gate/p2`, git 2.47.3, HEAD binary built from 505732d, isolated `HOME`):
    - Committed `cfg/local.yml` (`romeo committed`) and ran `git update-index --assume-unchanged cfg/local.yml`.
    - Replaced `cfg/` with a symlink to `../outdir3`, which holds `local.yml` (`sierra canary outside, assume-unchanged`).
    - `git status --porcelain=v1 -z --untracked-files=all --no-renames` printed only `?? cfg`, which the parser drops as a non-regular file.
    - `sh-agent search sierra` gave 1 hit, `cfg/local.yml:1`, with the outside text. `search romeo` gave 0 hits.
  - **Probe p1:** skip-worktree `sw/note.md` (`ls-files -v`: `S`), with `sw` a symlink to `../outdir`. `search oscar` returned the outside file.
  - **Control:** `sw2/note.md` (`H`) got the same symlink treatment. Git printed ` D sw2/note.md`, the path was dropped, and `search papa` found 0 hits.
  - **Reach:**
    - Wherever the symlink points, not only the checkout's parent as in finding 1.
    - Limited to file names the index holds under that directory, 1 MiB or less, not binary, and not secret-shaped by name.
    - A tracked config file marked assume-unchanged, the common "ignore my local edits" idiom, in a directory symlinked to a private config directory, puts that file's text into the 0600 project index and into `search` output, which agents read into their context. Nothing is sent anywhere.
    - The outside text is stored under the COMMITTED blob's ID. Any other path or branch holding that committed content then shows the outside text until `index --rebuild`.
  - **Trigger:** the user or an agent sets the bit and makes the symlink. `git sparse-checkout` sets skip-worktree on every path outside the cone, and `--assume-unchanged` is set by hand. A clone cannot deliver it: neither bit is cloned, and git does not check out a path through a symlinked parent.
  - **Untrue description:** `specs/sh-agent/search.md:35` says the project index skips "symlinks". A file reached through a symlinked parent is indexed.
  - **Remediation (stdlib, no dependency, closes the whole class):**
    - Open the checkout once per reconcile with `os.OpenRoot(root)` (Go 1.24; `go.mod` says 1.24.4).
    - Do `gitView`'s `Lstat`/`ReadFile` (`:126`, `:135`) and `readIndexable` (`:201`, `:205`) through it: `r.Lstat(p)`, and `r.Open(p)` or `fs.ReadFile(r.FS(), p)`. `Root.ReadFile` is Go 1.25.
    - An `os.Root` refuses any path that leaves the root by `..` OR by a symlink. That covers finding 1's shape and this one with one mechanism.
    - **Rejected:**
      - `filepath.IsLocal`: it checks the path text and misses symlinks.
      - `filepath.EvalSymlinks` plus a prefix check: longer, and racy.
      - Dropping `h`/`S` entries read from `git ls-files -v`: closes this trigger, not the class.
  - **Test:** p2's arrangement, plus p1's skip-worktree variant. Assert that the canary's word is not found. It must fail at 505732d.
