The trail holds no secret, no credential and no unframed instruction. govulncheck is clean apart from the known GO-2026-5024, which the code does not call.

## Hardening ideas (not findings)
- **H1 (older; this range adds `sh` and `readlink`):** `kit-preamble.sh:115` puts `$KIT_HOME/bin` first on PATH, and the trap then resolves `sh`, `find`, `cksum`, `readlink`, `sort`, `cut`, `ls` and `sed` through it. The run can write to that directory. Only a deliberately evasive run at the same uid could use this, which is the accepted design's scope (guide § 4: "not isolation"), and it gains no privilege. Fix: save PATH before `:115` and use the saved value inside `kit_on_exit`.
- **H2 (older):** `cksum` is CRC-32, which a deliberate writer can forge. A newline in a file name or a link target can also forge lines in the stream. If an evasive run ever enters the threat model, use `sha256sum` or `shasum -a 256` with NUL-separated names.
- **H3 (this range's new code path; `:85` is older):** there is a time-of-check gap between `[ -f "$p" ]` and `cksum "$p"`, and between `:85`'s lstat and open. A process still alive at exit can swap a fifo in and hang the trap. Under the new counting rule a hang is "did not reach the check", which is fail-safe.
- **H4 (this range's code path):** a regular file is still read through a link however long it is, for example `/proc/self/pagemap` (hundreds of GiB on x86-64), a file a live process keeps appending to, or an online-only cloud placeholder. The 30-second cases cover only `/dev/zero` and a fifo.
- **H5 (this range):** in F1's command, `.` is relative to the cwd, so a gate run from a subdirectory compares only that subdirectory. Use `':/'` and `':(top,exclude)…'`.
- **H6 (test hygiene, this range):** after `t.Fatal`, `TestKitPreambleAssertsCommit`'s 30-second cases (`catalog_test.go:1676-1704`) leave the hung child running: there is no context, process group or `WaitDelay`. This happens only on a regression.
- **H7 (carried):** `owner:` and `Range reviewed:` are lines their writer chooses.
