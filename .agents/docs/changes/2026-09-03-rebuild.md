# Rebuild: single-source harness with the `styrman` installer     (date: 2026-09-03)

## Summary

Rebuilt the harness after the hook-driven design was reverted (09fc5cc, 20a5abd). The harness is now context + skills + subagents only, installed by a small Go binary. Twelve design questions were put to the operator first; the answers are recorded in `.agents/docs/plans/2026-09-03-rebuild.md`.

- **Layout:** `shared/`, `claude/`, `antigravity/` collapsed into `context/`, `agents/`, `skills/`. No generated copies committed. `.agents/skills -> ../skills` so `npx skills add` from the repo root lands in `skills/`.
- **Context:** `context/AGENTS.md` rewritten without the binary, dispatch rows, scope digests, or hooks. Definition of Done is prose: tests, changelog, reviewer on 50+ lines / 5+ files, security on sensitive paths, docs on behavior change, commit and push. `context/dev-setup.md` holds the environment, stack, and GCP defaults (two placeholders to confirm).
- **Agents:** all six rewritten. `verifier` now runs the project's tests itself. Frontmatter is `owner:` + `date:`; descriptions are single-line and quoted.
- **Skills:** `audit`, `preflight`, `init-project`, `retro` rewritten; `handoff`, `distill`, `feedback`, `find-skills`, `VENDORED.md` edited to drop the binary. `init-project` now ships its templates in `assets/` and creates the `.claude/` symlinks and `CLAUDE.md` import. The other 19 skills are unchanged.
- **Binary:** `cmd/styrman` + `internal/harness` (stdlib only): install/sync, status, diff, update (`git fetch`, `pull --ff-only`, rebuild, reinstall), uninstall (manifest-only), list, render, adopt. Self-installs to `~/.local/bin/styrman`. Foreign `~/.claude/CLAUDE.md` is never overwritten.
- **Repo docs:** README, AGENTS.md, REQUIREMENTS.md (R1–R6), TODO, ROADMAP, ADR-001..005, this entry, and the rebuild checklist.
