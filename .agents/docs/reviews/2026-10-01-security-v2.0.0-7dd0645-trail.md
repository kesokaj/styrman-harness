    - The operator answered in their own turn (`changes/2026-10-01-1340-timer-per-home-and-two-decisions.md:7`).
    - So the sentence is an authorized record, not an injected permission.
  - **What the acceptance did not cover: rows that load third-party text.**
    - In this range, Phase 0 ran headless Antigravity with `read_file(*)` and `command(*)` over all 141 upstream entries, before any security review.

  - **Remediation.** Add one clause to § 4 (and to § 3f):
    - A row that loads vendored or third-party text (catalog entries, a refresh's diff) runs with read-only grants only. The `catalog-*` rows in `testing/skill-matrix.md` already specify this.
    - A probe of unreviewed upstream text runs after its security slice, or in real isolation.
