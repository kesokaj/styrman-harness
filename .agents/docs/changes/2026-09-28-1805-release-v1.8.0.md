## Release notes

## New features
- `sh-agent update --from-zip <file>`, a third way in, the zip place: a machine without your SSH key or `gh` installs the harness from a repository zip you downloaded by hand. The zip is read once and hashed, every entry is checked before anything is written, only the five harness trees are unpacked, and the unpacked copy is deleted. The output flags the zip `UNVERIFIED` (a zip carries no signature), and `status`/`diff` report that a zip install is not compared. REQUIREMENTS R8/R9, ADR-038; README § Install from a zip.
## Improvements and optimisation
- `sh-agent update --dry-run` is now read-only on both the checkout and the release path: it reports what an update would do and changes nothing. Before, it acted.
- A CLI token file (`antigravity-oauth-token`) is secret-shaped: the global context's commit rule, the installer's refusal and `.gitignore` all name it.
## Fixes
- A refused `--from-zip` leaves the home as it was (BUG-093).
- A test can no longer reach the network or your credentials; one red test run had pushed a metrics-only report (BUG-094).
## Other updates
- Deployed skills and agents no longer cite this repository's own bug IDs, ADRs or dated incidents; preflight and the others are universal.
- `testing/skill-matrix.md`: sandbox permissions follow the per-run rule, and state plainly that the allowlist is not a security boundary.
## Install
Download: see README § Install without cloning. Existing binary-only places: `sh-agent update`. Checkout places follow `main`. A machine without SSH or `gh`: README § Install from a zip.
