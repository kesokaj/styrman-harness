## Verdict: APPROVE WITH NITS

The spec (`specs/sh-agent/dream.md`) matches the round-2 code: agy stdin stream-json with a private HOME, the Claude strict flags, `toolPermission`, the SUCCESS result, the timer's absolute-only PATH, the one-hour cleanup guard.
