## Status: COMPLETE

## Verdict: FINDINGS (low and info only; nothing blocks the gate)

No secret, credential or private key is committed anywhere in the 51 paths. The credential-shape grep hits are prose describing the report redaction needles, the detection regex in `kit-preamble.sh:125`, and public SSH key lines with their fingerprints (`DECISIONS.md` ADR-026 and ADR-052, `deploy/remote.md` bridge block). All of these are public material, and all predate the range. The worst item is a low one. Two trail records commit the URL of the operator's private claude.ai artifact. It is not a credential: access still depends on the claude.ai account. It is an identifier that should be judged with the others `remote.md` already lists before the repository is ever made public. The kit scripts, read as code, hold up. `kit-preamble.sh` resolves its kill roots once, makes them readonly and refuses `/`, the home, the checkout and their parents. It matches the environment with `grep -qzxF` and never reads it into a variable. It prints only a sanitised exe basename, never argv. Every git call in the kits runs with inherited `GIT_*` variables cleared. Instruction-shaped text aimed at agents appears once, as a deliberate canary.

  - **Why this is no new finding:** this is the accepted design, recorded in `guide.md` § 4 (operator, 2026-10-01: "not isolation"; the agent shares the operator's uid either way). It is unchanged in this range.
  - **What the range did:** it only moved the leftover-process check into the preamble.

- **[info / confidence: medium]** `.agents/docs/testing/kit-preamble.sh:158-186` (`kit_process_leftovers`): the residual R2-2 of `reviews/2026-10-08-security-worktree-kit-leftovers.md` stands, by design. A kit root that is a child of the home but holds real work (`KIT_CLONE=$HOME/other-project`) passes the guard, and its same-uid processes would get SIGTERM. A mutation run against the real checkout already did this once on 2026-10-08 (`changes/2026-10-08-0901-…:46`, `handoffs/2026-10-08-0914-…:122-127`). That is the operator's call, recorded here so a reader does not take the preamble guard as complete.
