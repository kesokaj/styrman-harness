## Failure modes

- A context edit that pushes the render over 22,000 fails `TestRenderedContextFitsAntigravityBlock`; over 15,000 fails `TestRenderedContextUnderTarget`.
- A skill or agent that no longer parses fails `sh-agent install --home .agents/scratch/x` with the file named.
- A behavioural run that proves nothing (auto-denied, no skill loaded) is reported as such, never as n/N; the kit preamble asserts the fixture before the CLI starts.
- A struck skill leaves no dangling reference: `TestSkillLinksResolve` and `grep -rn python\|anti-ui-slop` over context, skills, docs.
- A REQUIREMENTS edit is made only after the operator approves its exact text (D29a); until then the phase ships without it and the task stays unticked.
- The real-home install fails the smoke checks → `sh-agent install` from the last good commit, reported.
