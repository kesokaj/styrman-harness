# Release v1.13.0     (date: 2026-09-30)

## Summary
v1.13.0 is gated SHIP over `v1.12.1..c63f736` (`reviews/2026-09-30-preflight-v1.13.0.md`). A MINOR: `sh-agent search` and `sh-agent index`, a per-checkout SQLite index of every file and trail record plus a global search index, reconciled against git before every answer; the context, seven agents and eight skills use it; one dependency (R4 as amended, ADR-045). The gate's four reviews found seven low findings; five were fixed before the tag with tests that failed first, two are documented limits by the operator's choice.

## Type
release

## Release notes
## New features
- `sh-agent search`: ranked full-text search (SQLite FTS5) of every file and trail record in a git checkout, with each record's status on the hit. `--refs <BUG-NNN|ADR-NNN|path>` lists every record naming an ID, a file or a directory; `--open` lists open bugs and plans with unticked boxes; `--kind` and `--limit` filter (`changes/2026-09-29-1839-search-index-phase-1.md`).
- `sh-agent index`: reconciles or rebuilds the index and prints its counts. The index is a cache at `.agents/scratch/search.db`, checked against git before every answer, so it never answers from another branch. No service runs.
- `--global`: one search over `~/.config/sh-agent/`'s feedback, retros and proposals and the trail of every harness project that has used search (`changes/2026-09-29-1844-search-index-phase-2.md`).
- The context and the agents use it: a "Search first" entry, `sh-agent search --open` in the resume reading order, and a search step in seven agents and eight skills (`changes/2026-09-29-2009-search-index-phases-3-4.md`, `changes/2026-09-29-2326-search-release-readiness.md`).

## Improvements and optimisation
- Index build 2.2 s to 1.7 s and index size 24.1 MB to 21.7 MB on this repository, with identical results; a warm search answers in 25 to 40 ms.
- Measured, not assumed: recall 0.677 against 0.379 for one grep pass on 41 questions; same quality and the same cost on sample apps; the main agent searches in 6 of 6 large-trail sessions (`testing/2026-09-29-search-recall.md`, `testing/2026-09-29-search-adoption.md`).

## Fixes
- BUG-106, BUG-107: test kits ran fixture clones inside the checkout and registered them in the real home's global search index; both rules are now in the project `AGENTS.md`.
- BUG-108: a work-tree rename was misparsed and could make search read a file outside the checkout; `git status` runs with `--no-renames`, and every file read now goes through an `os.Root` (`changes/2026-09-30-0505-v1.13.0-gate-fixes.md`).
- BUG-105: the preflight gate writes its verdict last, after reading its own "What was not checked" list (`changes/2026-09-29-2336-preflight-verdict-last.md`). BUG-083 closed on the evidence of 31 verifier dispatches.
- Security review findings fixed before release: database path escaping, registration only for checkouts with `.agents/docs`, output free of control characters, private index files (mode 0600), a refused symlinked database file, and secret-shaped files never indexed.

## Other updates
- REQUIREMENTS R4 now allows exactly one dependency, the pure-Go driver `modernc.org/sqlite` v1.46.1 (ADR-045, ADR-045a). A checkout's first build of this version fetches it from the Go module proxy; release-binary and zip places are unaffected.
- Known limits: `govulncheck` reports GO-2026-5024 in `golang.org/x/sys`, not reachable from this code; a file edited and restored while a search waits for the lock stays indexed with the edit until `sh-agent index --rebuild`; an index that arrives with a copied project directory is trusted as it is, so run `sh-agent index --rebuild` after copying a project in. Vectors were tested and not adopted.
