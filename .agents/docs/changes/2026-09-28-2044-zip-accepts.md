# The zip place accepts the zip it is given     (date: 2026-09-28)

## Summary
The operator reversed ADR-040 before any release carried it: "Don't complicate things. Just accept the zip. This is a workaround for environments that can't use the normal way." (ADR-041).

**Removed:**
- `--unverified`;
- its refusal;
- the stray-argument refusal added for `--unverified false`.

**Now installed, marked `UNVERIFIED`:** a zip without the full `SHA256SUMS`/`SHA256SUMS.sig` pair beside it, whether neither file or only one. The code now matches R9's v1.9.0 text exactly.

**Unchanged:**
- A zip with the pair is still verified automatically, and refused if the check fails.
- An older release's zip installs.

The tests from the gate fixes stay: the three refusal tests assert their own refusal, and failed-check refusals never suggest installing unverified.

feature
