## Answers to the dispatch's questions

- **Split.** Files with CR-only line endings (old Mac) were refused before and still are, because `Cut` on `\n` fails ("no YAML frontmatter block"). A closing `---` or `---\r` at end of file with no newline still closes the block (probe). CRLF files still load. The only files that newly fail are those with `---\r\r` (for example a CRLF file converted to CRLF a second time). An opening `---\r\r` now reports "no YAML frontmatter block", and a middle one leaves the block open: `ParseStrict` refuses it through `unreadLine` (finding 3), or the block is "unterminated". The other splitters agree with the stricter rule. `opensFrontmatter` (`inventory.go:417`) trims `\r` through `unicode.IsSpace` and still refuses a command or rule whose first line is `---\r\r`. The catalog tests and index writer call `Split` itself. `DeriveAgy` writes `\n` fences. `internal/search/parse.go:103` uses a looser `TrimSpace` rule, but only for indexing, not the installer's lint, and it is outside the range.
- **printable.** Legitimate text changes in output only. A ZWJ inside an emoji sequence becomes `👨?👩?👧`, a ZWNJ in Persian becomes `می?خواهم`, a soft hyphen and a leading BOM each become `?` (all probed or pinned by the test). The index stores the raw text, because `printable` is called only at print sites. Snippets go through it (`cleanSnippet`), labels and paths through `label`, and the header's left-out names through `status()`. The header's phrase is `%q`-quoted, so Cf characters are escaped there. The `--refs` lines (`markTarget`) and the `--open` lines all pass through it. The unwrapped prints (`x` at 755/758/765) are the operator's own argument. The doc comment at line 613 still says only "C0, DEL, C1", but the inline comment covers the rest. That is not a finding.
- **Timer.** `OtherSystemTimerFiles` returns the plist on linux, the `.service` and `.timer` files on darwin, and nil for an unknown goos, so no note is printed there. On a home with both systems' files, linux removes its own two files and the note names the plist. The two path sets are disjoint, so uninstall cannot name a file it just removed. The note prints on uninstall, on uninstall `--dry-run`, and on `--remove-timer`, but not on `--remove-timer --dry-run`: that gap is finding 1.

After a failure the operator is told the role, and for a fetch the exact directory to run `git fetch` in. It reuses the existing work clones, then proves a later refresh still succeeds.

Every test that needs one sets it on `cmd.Env` or through `t.Setenv` (`harness_test.go:779`, `report_test.go:407`, `collect_test.go:479`, `main_test.go:745`). ### What else the delta adds

- **Line-break refusal.** `Split` returns the block with each line's own terminator (`SplitAfter`), so in a CRLF file every block line ends `\r\n`, even when the file's last line (the fence or the body) has no newline. Such a file still loads (probe, and the test's CRLF case). CR-only (old Mac) files are refused earlier by `Split` ("no YAML frontmatter block"), unchanged since round 1. A U+2028 inside a quoted description is refused with a message that names it (probe). A YAML 1.2 reader would not break the line there, so this is over-refusal in the safe direction. A doubled `\r` is refused as a lone carriage return, which is accurate. `ContainsAny` decodes runes, so `…` (U+2026) and invalid UTF-8 bytes are not mistaken for NEL.
- **`indentedBeforeKey`.** Probes on the copy:
  - A column-0 comment followed by a key loads (test case and probe).
  - An indented comment first is refused as "indented before any key". This is over-refusal: YAML ignores the comment, and the message's reason (a top-level map) does not fit a comment. It is the safe direction, and no harness file has it, so not a finding.
  - A tab-indented first line is refused.
  - `- x` first loads, and the lint sees no key in it. A YAML reader refuses the whole document (a sequence, then a map), so no key is hidden. This is the column-0 list skip from BUG-143, unchanged here.

The anchor line itself is read as key `x`, and the merge is refused.
