## What changed

- **Verbs as a table, one FlagSet per verb (S2, IN5).** `cmd/sh-agent/main.go` holds `verbs map[string]verb` with each verb's own flags beside the three global ones; a flag another verb owns is a usage error (`flag provided but not defined`, exit 2), a stray positional argument on a verb that takes none (`list foo`, `list - --check`, `update -- --from-zip x`) is refused with `<verb> takes no arguments`, exit 2, before the verb runs; `--` keeps everything after it positional for `reorder` and the flag package alike (one marker re-emitted ahead of the positionals); `reorder` derives the value-taking flags from the FlagSet (the hand-kept map is gone). Usage errors exit 2 on every verb (D41; README documents the overlap with `update --check`'s exit 2 for "behind").
- **Settings code in `internal/harness/settings.go` (S1):** `AttributionSet`, `AttributionHint`, `ReadSettings` with their tests; refuses a linked `settings.json` AND a linked directory above it (`underLink`, the installer's rule), writes atomically, `O_EXCL` on create.
- **Origin strings (IN6):** `State.Origin()`, `ParseOrigin`, `Source.OriginString()`, `ZipOrigin` replace six hand parses in two packages. **`ResolveSourceLenient` (IN7)** for `report`. **`pathHint`/`AttributionHint` return nothing (IN9).** **IN14** was already satisfied (the audit counted `status`'s call).
- **No system temp dir (IN10):** the zip signature check's signers file and the no-config dry-run unpack go beside the zip, removed on every path; `TestNoSystemTempDirInSource` walks every package for `MkdirTemp("", `/`CreateTemp("", `. The zip's folder must be writable (README, `delivery.md`).
- **One `ReadCapped` (S7)** used at four sites, failing closed one byte past the cap on streams too; `copyCapped` for zip entries. **One PATH walk (S6)** `pathCandidates`. **`ParseStrict` (S8)** parses and lints in one pass; `Parse`/`Lint` stay as thin wrappers. **S5:** incident-narrative comments in `main.go`, `repo.go`, `report.go`, `pathguard.go`, `release.go`, `zip.go`, `frontmatter.go` cut to the rule plus the bare reference.
- Docs: README § Daily commands (`index` refuses search-only flags; usage errors exit 2; the zip paragraph), `search.md` exit statuses, `delivery.md` § The model (beside-the-zip, writable folder), `testing/guide.md` § 3b, `sh-agent-matrix.md` two rows (refused flags, refused stray arguments).
