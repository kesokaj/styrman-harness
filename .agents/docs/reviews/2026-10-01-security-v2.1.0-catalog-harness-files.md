## Verdict: FINDINGS

Nothing is high or medium. There are six lows.

The worst is in the catalog's instruction text. Five `## Notes` lines in MANIFEST.md re-open what router steps 4 and 5 forbid outright:
- an MCP server or plugin "with the operator's approval", where the router says not even on a go inside an entry's flow;
- `gcloud config set project` once the operator names the project;
- `--quiet` in cases the router says are not followed.

The router makes a note the text that wins with the entry open and never ranks a note below its own steps. So for these five entries the note is less safe than no note.

The second is a residual of the gate's `--dest` fix. A path with a component that does not exist yet, followed by `..` (`<checkout>/x/..`), passes both destination checks. The script's own `mkdir -p` then turns it into the checkout, the home directory or `skills/`. This was reproduced on a copy of the guard.

The third: BUG-149's fix names the wrong platform as its limit. On macOS, Go reads the account database without cgo. On Linux the release binaries are built without cgo, and for an account not in `/etc/passwd` the lookup falls back to `$HOME`, the variable the fix was meant to stop trusting.

INDEX.md, CHECKSUMS, `.sh-agent-noindex` and the two licences are clean. `go.mod` and `go.sum` are unchanged since v2.0.0. `govulncheck` finds nothing reachable. The delta has no secret.

- **[low / confidence: high]** `skills/google-catalog/scripts/refresh-catalog.sh:70-88`, with `:247` and `:263` — `phys()` resolves a spelling only through a path that exists or a parent that exists.
  - **The bypass.** A `--dest` holding a component that does not exist yet, followed by `..`, is compared as typed. Examples: `<checkout>/x/..`, `<checkout>/skills/x/..`, `~/x/..`, `<checkout>/a/b/../../..`. The spelling passes the three `case` guards. The not-a-catalog check (`:86`) is skipped, because `[ -d "$dest" ]` is false. The script's own `mkdir -p "$dest"` (`:247`) then makes the spelling name the real place, and `cp -R "$build/." "$dest/"` (`:263`) writes the catalog there.
  - **Reproduced on a copy.** I ran lines 64-88 of the f62513b script with stand-in checkout and home directories under scratch:
    - `<repo>` and `<repo>/skills/..` were refused (the fixed cases);
    - `<repo>/nonexist/..` and `<repo>/skills/new/../..` passed, and after `mkdir -p` they are the checkout;
    - `<home>/nope/..` passed and is the home directory;
    - `<repo>/a/b/../../..` passed and is the checkout's parent.
  - **Effect, traced by reading.**
    - The first run deletes nothing, because no CHECKSUMS is there yet. It writes 136 entry directories, INDEX.md, MANIFEST.md, CHECKSUMS, LICENSE-* and `.sh-agent-noindex` into the target.

- **[low / confidence: high]** `internal/dream/timer.go:32-45` (`accountHome`), `.agents/docs/specs/sh-agent/dream.md:46` and `bugs/BUG-149` — the stated limit names the wrong platform, and the real one is open.
  - **What the Go sources say** (go1.27.1, `$(go env GOROOT)/src/os/user`):
    - On darwin, `os/user` calls libSystem even without cgo (`cgo_lookup_syscall.go`, `//go:build !osusergo && darwin`). So macOS release binaries do read the account database.
    - On Linux without cgo (`lookup_stubs.go`, `(!cgo && !darwin …)`), `user.Current()` reads only `/etc/passwd`. For an account not listed there (LDAP/SSSD/AD, systemd-homed, a container uid), it returns `os.UserHomeDir()`, that is `$HOME`, with `err == nil` whenever `$USER` is set.
  - **Consequence.** The release binaries are built `CGO_ENABLED=0` (`testing/2026-10-01-verify-v2.1.0-gate.md:28`). On a Linux release binary for such an account, `accountHome` returns the sandbox's `HOME`, and BUG-149's sandbox `--remove-timer`/`uninstall` path is back without a word. `TestUnitForIgnoresHomeOverride` skips there by design.
  - **Exposure.** No place is known to use such an account, and the operator's box builds from the checkout.
  - **Remediation.**
    - Use `user.LookupId(strconv.Itoa(os.Getuid()))`, which has no `$HOME` fallback in either build.
    - On error, fail closed: give every home the suffixed names and print one note.
    - Correct the limit in the comment, the spec and BUG-149. The change log is append-only, so the correction goes in the next entry.
