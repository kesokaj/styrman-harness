# Release v2.7.0

## Type

release

## Summary

A MINOR release (the operator's choice). Gate: `reviews/2026-10-12-preflight-v2.7.0.md`, VERDICT SHIP. Accepted and named here: after the dream job kills itself on a signal, `dream --all` could start the next project's CLI in the microseconds before the process dies (reviewer round 2, low confidence; untestable without killing the test process); redaction's known limits are `net use … /user:` and any shape the command-line class misses.

## Release notes

A MINOR release: an allow-list for agent frontmatter, `--vendor` checked before any command runs, wider credential redaction, and fixes to the dream job's signal handling and the installer's usage errors. Nothing a harness place uses is removed.

## New features
- **Agent frontmatter is an allow-list** (ADR-056, ADR-056a). An agent may set only `name`, `description`, `tools`, `model`, `maxTurns`, `skills`, `effort` and `color`. `install` refuses any other key (`hooks`, `permissionMode`, `mcpServers`, `memory`, `initialPrompt`, `isolation`, `disallowedTools`, or a vendor's next key).
  - If you added agents of your own, check their frontmatter before updating.
  - The release also brings the dream job's nohup fix (BUG-170) and moves the list of Claude Code setups needing the `@AGENTS.md` stub into the init-project skill, so the context's pointer resolves at every place (ADR-057).

## Improvements and optimisation
- **`sh-agent report` and the dream job redact more credential shapes.** A credential on a command line is caught after any punctuation, inside argv arrays, quoted, or after an escaped line break. So is a password flag of mongosh, sqlcmd, LDAP tools, OpenSSL (`pass:`), keytool and lftp. Redaction remains a safety net: a shape it misses is a known limit (`net use … /user:` is one).

## Fixes
- **The project review's fixes** (BUG-167, BUG-168, BUG-169):
  - the delivery spec is pinned to the newest release;
  - usage errors exit 2 at seven more places;
  - a helper the dream CLI starts can no longer hold the nightly run and its lock;
  - `mcpServers` is refused in an agent.
- **`--vendor` is checked first, on every command** (BUG-171). `update --vendor <typo>` used to pull the checkout before refusing. Also in this release:
  - the dream job no longer loses a signal that arrives as a CLI exits;
  - `dream --install-timer` refuses a home holding a quote, a backslash or any control character.

## Other updates
- **The project review of 2026-10-09:** six lenses, 29 rows, records only.

## Install or update
- **A checkout place:** `sh-agent update`.
- **A binary-only place on v2.4.0 or later:** `sh-agent update` downloads v2.7.0 and checks it against `SHA256SUMS`.
- **A place still on v2.3.2 or older** cannot update past the v2.4.0 bridge by itself. Replace `~/.local/bin/sh-agent` with this release's binary for your platform by hand, then run `sh-agent install`.
- **A zip place:** download `styrman-harness-v2.7.0.zip`, then run `sh-agent update --from-zip styrman-harness-v2.7.0.zip`.
