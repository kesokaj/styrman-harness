# Release zips are signed; `update --from-zip` verifies them     (date: 2026-09-28)

## Summary
The v1.8.0 gate's open medium, an unsigned zip becoming the agents' instructions, is narrowed as the operator approved ("All approved").

**Release side.** Each release publishes `styrman-harness-vX.Y.Z.zip`, a `git archive` of the tag, under the signed `SHA256SUMS`. Release step 3b has the host's own built binary verify that zip before anything is published.

**`--from-zip` with sums beside the zip.** When `SHA256SUMS` and `SHA256SUMS.sig` sit beside the zip, it verifies the signature against the compiled-in signer, then the zip's line against the hash of the one buffer it unpacks, before any write. It prints `VERIFIED against the signed SHA256SUMS of release vX.Y.Z`. It refuses:
- a failed signature or checksum;
- a missing half of the pair;
- stale sums from another release;
- a renamed zip;
- an unreadable folder.

No refusal suggests removing the checksums.

**`--from-zip` with nothing beside the zip** (a `main` zip) still installs, marked `UNVERIFIED`, as R9 allows. Whether that should need `--unverified` is open and put to the operator (ADR-039 Open).
