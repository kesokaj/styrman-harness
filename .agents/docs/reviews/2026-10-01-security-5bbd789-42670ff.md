## Verdict: FINDINGS

One medium, four lows, no high. Worst: this range made the catalog pin a full 40-digit id and REMOVED the only check after the checkout, on the reasoning that git never lets a ref redirect a full id. That holds for `rev-parse` (the previous round probed only that), not for `git checkout`: a local branch named exactly the pin's 40 digits wins over the object, and `git clone` creates one local branch, the source's default branch. A source that names its default branch after the pin the operator will pass makes the refresh vendor another commit, exit 0, print no warning, and still accept a pin the source does not even contain. Probed with the script's own clone and checkout commands on scratch fixtures (git 2.47.3). The four lows: the verifier still runs edited scripts and kits with no quote, the gate's verification row now accepts the gated agent's own log for edited commands, the gate reads plan tiers only from the endpoints' active plan, and the kit fingerprint (with `-L`, new here) misses a new looping symlink and two older cases its comment does not state.

## Hardening ideas (not findings)
- `refresh-catalog.sh:239-240`: compare `full_a`/`full_g` with the pins before the manifest is written; a mismatch is a refusal, whatever the checkout did.
- `kit-preamble.sh:74-75`: `-L` makes the exit check read everything a link in the config reaches (a link to `/` reads every readable file; only a CRC leaves `cksum`, and a FAIL is delayed, never turned into a pass). `-H` plus `-type l` files, above, bounds it.
- `kit-preamble.sh:99` (older): the wrapper pins `--home` by position; `cmd/sh-agent/main.go:204` registers `home` on each verb's FlagSet, and Go's `flag` keeps the last value, so an agent's own `--home <path>` after the verb overrides the pin (read, not run). Only the fingerprint catches what follows; the wrapper could refuse a call that carries its own `--home`.
- `cksum` is CRC-32 (older): a change detector, not collision-resistant; the threat is accidental writes.
- Pins are SHA-1 ids; git's collision-detecting SHA-1 covers the known attacks; no finding.
