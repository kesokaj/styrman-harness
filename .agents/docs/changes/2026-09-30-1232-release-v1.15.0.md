## Release notes
A MINOR: the `verifier` agent's long-suite rule changes, and two released behaviours are fixed. Everything the operator asked to be completed on 2026-09-30 is in this release.

### Improvements and optimisation
- `verifier` agent: a suite that takes minutes runs once in the foreground with the call's timeout raised to the tool's maximum and its output redirected to a file; only a suite past that maximum runs in the background, and every background job is ended before the hand-back, so an agent no longer stays open after it reports (the harness proposal queued since 2026-09-23; behavioural run: 0 of 3 background calls against 2 of 3 for the old text).

### Fixes
- `sh-agent status` and `sh-agent search --global` listed harness proposals through a glob built from the home path (`LastRetro`, `configView`); both list by name now, so a home path holding `[`, `*` or `?` finds its proposals (BUG-109's class, the last two sites).
- `sh-agent report`: the credential families a review named as not covered — a Google refresh token, Discord and Teams webhooks, SendGrid keys, Azure storage keys, cookie headers and `curl -b` lines, Vault tokens, age keys, DigitalOcean tokens, a JWT with a short or empty middle segment — each have one rule, widened once for near shapes; the deploy guide says what the rules reach and that a shape past them is a design question, not another batch (BUG-110 closed for instances).

### Other updates
- Project `AGENTS.md`: `commands/` and `rules/` are empty by design (this repository only).
