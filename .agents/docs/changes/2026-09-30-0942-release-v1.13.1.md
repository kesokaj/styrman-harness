# Release v1.13.1     (2026-09-30)

## Release notes

A PATCH: fixes to released behaviour, nothing an installed place gains or must react to. Found by `/review --project --all` over v1.13.0 and fixed the same day.

### Fixes
- BUG-109: `sh-agent update` on a release-binary place swept leftover `release-*` download directories with a glob built from the home path; a home holding `[`, `*` or `?` matched a sibling directory's entries and removed them, and a second concurrent update could delete the first's directory. The sweep now lists by name, skips symlinks and files, and waits an hour, like the zip sweep it also replaces (`changes/2026-09-30-0758-review-project-fixes.md`).
- BUG-110: `sh-agent report`'s redaction missed common credential shapes with no keyword on the line — JWTs, Stripe live and test keys and webhook secrets, npm and Hugging Face tokens, PyPI tokens, Slack webhook URLs, OpenAI service, admin, None and legacy keys, and a bare token as a URL's userinfo — and a token after a literal `\n` or an underscore. Twenty needles and three per-kind rules added (the release gate added GitHub `ghr_`, GitLab deploy, runner and pipeline-trigger tokens, and gave Stripe keys a length so `task_test_` is not one); the accepted over-redaction (a long username, a pathless URL followed by an unrelated `@`) is pinned in the tests, and the deploy guide now says which vendor families the list does not cover (`changes/2026-09-30-0910-redaction-per-kind-rules.md`, the gate-fix entry).
- BUG-111: `gke-basics` and `terraform` had no recorded source or pin. Both are recorded as forks with their upstream base (google/skills 6f0b877; antonbabenko/terraform-skill v1.6.0) and their local changes; a test refuses a manifest row without a repository and a pin. No skill content changed.
- BUG-112: the settings writer and the installer each had their own atomic write; one `WriteAtomic` now serves both and names a temp file it could not remove. A failed `report` push is reported with URL credentials scrubbed, as a failed clone already was.

### Other updates
- ADR-046 records an accepted risk: a checkout place follows the tip of `main` after `git pull` with no commit-signature check, by design (R9); release-binary places verify signed checksums as before.
- Every description of the harness names the search index (README, the project `AGENTS.md`, the delivery spec, the GCP guide) — a docs fix after v1.13.0 (`changes/2026-09-30-0623-docs-name-search-everywhere.md`).

### Install
Download: see README § Install without cloning. Existing binary-only places: `sh-agent update`. Checkout places: `sh-agent update` pulls `main`. Zip places: `sh-agent update --from-zip styrman-harness-v1.13.1.zip` with `SHA256SUMS` and `SHA256SUMS.sig` beside it.
