# Release v1.1.0 — the release binary, and a report that keeps nothing     (2026-09-17)

## Summary

v1.1.0 is the first release whose tag carries binaries. A machine can now install the harness from one downloaded `sh-agent` with `context/`, `skills/`, `agents/`, `commands/` and `rules/` built into it, and `sh-agent update` at such a place downloads the newest release, verifies its signed checksums against a signer line compiled into the binary, and replaces itself. `sh-agent report`, itself new since v1.0.0, no longer keeps a clone of the private feedback repository on any machine: each run clones a throwaway holding only that machine's own reports and removes it after the push. MINOR: every v1.0.0 install keeps working, `state.json`'s shape is unchanged, and nothing an existing deployment must react to.

The release notes as published are `.agents/scratch/release-notes-v1.1.0.md`, read by the operator before the upload; their four groups are reproduced by the gate report's finding list and the phase entries below.

## Verification

`VERDICT: SHIP`, `.agents/docs/reviews/2026-09-17-preflight-v1.1.0.md`, range v1.0.0..f129aa7. Thirteen findings were raised and all thirteen were fixed before the tag rather than accepted as release risk — among them a downgrade hole (a genuinely signed older release installed and verified honestly), a guard that deleted the operator's only copy of unpushed work when it could not count it, a read-only `--check` that deleted files, `go:embed` shipping untracked files, a dry run that looped forever on an unreadable directory, and a permanent push refusal misdiagnosed as a race. At the tag: 102 top-level tests and 85 subtests, none failing or skipped; `gofmt`, `go vet`, `go test -race -count=1 ./...` and `govulncheck` clean on go1.27.1. The release procedure was rehearsed end to end in `.agents/scratch/v110-rehearsal/`, including a binary updating itself from the rehearsed assets and refusing three tampered variants, and the embed-contamination guard was exercised in both directions. Not exercised, and named in the gate report: no real release existed before this one, so every download was against a fake `gh`; `darwin/arm64` and `linux/arm64` were built but not run; `go install …@v1.1.0` could not be tested before the tag; the work Mac e2e is owed.
